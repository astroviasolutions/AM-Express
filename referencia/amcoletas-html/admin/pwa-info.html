Como instalar o Aplicativo

Instruções para compartilhar com os usuários:

Android
  1. Abra o site no navegador Chrome
  2. Toque no menu (três pontos) na parte superior direita
  3. Selecione "Adicionar à tela inicial" ou "Instalar aplicativo"
  4. Confirme a instalação
iOS (iPhone/iPad)
  1. Abra o site no navegador Safari
  2. Toque no ícone de compartilhamento (quadrado com seta para cima)
  3. Role para baixo e toque em "Adicionar à Tela de Início"
  4. Confirme a instalação
Desktop (Windows/Mac)
  1. Abra o site no navegador Chrome, Edge ou Safari
  2. Procure pelo ícone de instalação na barra de endereços (geralmente um ícone de "+" ou um ícone de computador)
  3. Clique no ícone e depois em "Instalar"
